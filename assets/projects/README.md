# Screenshots dos projetos

Coloque aqui as screenshots reais dos projetos. O portfolio tenta carregar automaticamente estes arquivos:

- `facilix.png`
- `portfolio-pessoal.png`
- `vollopay.png`
- `doacao-bezerros/produtor-carne-01.png`
- `doacao-bezerros/produtor-carne-02.png`
- `doacao-bezerros/produtor-carne-03.png`
- `doacao-bezerros/visao-geral.png`
- `caminhodv.png`

Enquanto algum arquivo nao existir, o card mantem um placeholder identificado com o caminho esperado.

Quando adicionar uma nova screenshot, inclua o PNG com o nome correspondente e substitua o placeholder no HTML por uma tag `img`, ou marque o `figure` com `data-preview-ready="true"` para o loader trocar automaticamente.

Para o projeto Portal Agropecuario de Doacao de Bezerros, o carrossel carrega automaticamente as imagens existentes em `assets/projects/doacao-bezerros/`. A recomendacao e usar PNG em proporcao 16:9 ou proxima, com largura entre 1200px e 1600px.
