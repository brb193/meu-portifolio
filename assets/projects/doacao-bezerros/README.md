# Screenshots do Portal Agropecuario de Doacao de Bezerros

Coloque nesta pasta as screenshots reais do projeto academico.

Arquivos esperados pelo carrossel:

- `produtor-carne-01.png` - tela do Produtor de Carne, visao inicial e bezerros disponiveis.
- `produtor-carne-02.png` - formulario de adocao, meus bezerros e extrato de pontos.
- `produtor-carne-03.png` - tela do Produtor de Carne, secao final complementar.
- `visao-geral.png` - visao geral das quatro interfaces do projeto.

Formato recomendado: PNG, proporcao 16:9 ou proxima, largura entre 1200px e 1900px. Enquanto nenhum arquivo existir, o portfolio mantem o fallback de screenshot pendente. O carrossel usa automaticamente apenas os arquivos que existirem.
